읽을 때는 이해한 것 같아도, 설명하려 하면 멈추는 순간이 있습니다. 이 블로그는 그 사이를 조금씩 메우기 위한 공간입니다. 기술을 익히는 과정과 논문을 읽으며 생기는 질문을 내 언어로 남기려 합니다.

## 무엇을 기록할까

기록은 세 갈래로 나눕니다. 형식보다 중요한 것은 나중에 다시 읽었을 때 생각의 흐름을 따라갈 수 있는가입니다.

| 분류 | 남기고 싶은 내용 |
| --- | --- |
| 기술 | 문제의 맥락, 구현 과정, 선택의 이유 |
| 논문 노트 | 논문의 질문, 핵심 아이디어, 이해한 범위와 한계 |
| 학습 기록 | 짧은 발견, 헷갈린 개념, 다음에 확인할 질문 |

완성된 답만 적기보다 아직 모르는 부분도 구체적으로 표시하겠습니다. 같은 문제를 다시 만났을 때 출발점을 찾을 수 있도록요.

## 코드는 맥락과 함께

짧은 코드에도 입력과 결과를 함께 남기면 다시 읽기 쉽습니다. 다음 함수는 숫자 배열의 산술평균을 구합니다. 값이 없을 때는 평균을 정의할 수 없으므로 오류로 알립니다.

```typescript
function mean(values: number[]): number {
  if (values.length === 0) {
    throw new Error('하나 이상의 값이 필요합니다.');
  }
  return values.reduce((sum, value) => sum + value, 0) / values.length;
}

mean([2, 4, 6]); // 4
```

작동하는 결과뿐 아니라 전제와 예외를 설명하는 습관을 들이고 싶습니다.

## 수식은 문장으로 풀어 쓰기

같은 평균을 수식으로 쓰면 다음과 같습니다. $n$은 값의 개수이고, $x_i$는 $i$번째 값입니다. 여기서는 $n > 0$을 전제로 합니다.

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i
$$

기호를 옮기는 데서 멈추지 않고, 무엇을 나타내는지와 어떤 상황에서 쓰이는지를 함께 설명하겠습니다. 논문을 읽을 때도 저자의 주장과 내 해석을 구분해 적으려 합니다.

## 기록을 이어가는 방법

하나의 글에 모든 것을 담기보다 하나의 질문을 분명히 다루겠습니다. 근거가 되는 문서와 논문을 연결하고, 생각이 바뀌거나 오류를 발견하면 내용을 고치고 수정 날짜를 남기겠습니다.

작은 기록이 쌓이면서 이곳이 다시 찾아 읽을 수 있는 학습 노트가 되기를 바랍니다.
