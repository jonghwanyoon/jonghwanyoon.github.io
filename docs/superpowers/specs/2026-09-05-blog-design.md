# Jonghwan.log 블로그 디자인

기존 Astro 블로그의 글과 디자인을 초기화하고 GitHub Pages에서 기술 글, 논문 요약, 학습 기록을 게시한다. 별도 백업은 생성하지 않는다. 배포 저장소는 jonghwanyoon/jonghwanyoon.github.io, 기본 브랜치는 master다.

사용자가 선택한 흰색·검정·파란색 테크 스타일을 적용한다. 짧은 소개와 글 목록을 중심으로 넉넉한 여백, 선명한 제목, 얇은 구분선, 절제된 파란색 강조를 사용한다. 한국어 UI를 기본으로 하며 독립적인 모바일 레이아웃과 시스템 테마에 따른 라이트/다크 모드를 제공한다.

홈, 전체 글, 분류, 태그, 소개, 개별 글을 정적 생성한다. 검색은 제목·요약·태그·본문에서 한국어와 영문을 찾는다. 본문은 자동 목차, 읽는 시간, 코드 강조와 복사, 수식, 표를 지원한다. RSS, 사이트맵, canonical 메타데이터를 제공한다. 글이 없는 분류는 빈 상태를 표시하며 연구나 게시물 수를 꾸며내지 않는다.

Markdown 콘텐츠에는 title, description, pubDate, category(tech/papers/notes), tags, draft를 사용한다. 초안 및 미래 글은 공개 페이지·검색·RSS·사이트맵에서 제외한다. 논문 정보는 선택적인 paper 객체에 보관한다. 실제 요약 대신 블로그 안내 글 한 편만 게시하고 기술 글·논문 요약 템플릿은 templates에 둔다.

Astro 7와 기존 npm 잠금 파일을 유지하며, 수식용 remark-math와 rehype-katex를 추가한다. GitHub Actions에서 테스트와 빌드를 통과한 정적 결과만 배포한다. 검색과 공개 여부 로직, 생성된 링크·메타데이터·초안 제외를 검증한다.
